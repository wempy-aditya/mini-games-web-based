Sentinel bisa memakai model keputusan untuk menyusun gelombang. Semua isian disimpan lokal di peramban ini dan hanya dikirim ke URL yang kamu ketik. Game tanpa model tetap bisa dimainkan penuh.

Otomatis mencoba langsung, lalu memakai relay dev server kalau peramban menolak koneksi. Relay dibutuhkan untuk API yang memakai CORS, karena peramban mengirim pemeriksaan awal tanpa header otorisasi sehingga server membalas 401 tanpa header CORS.

CARA MAIN

Tujuan

Musuh berjalan mengikuti jalan menuju inti. KamuunhaSAS placing menara untuk menghentikannya. Kalau 20 musuh lolos, permainan berakhir.

Menara

  • Panah — murah dan cepat, satu target.
  • Meriam — ledakan area, berat di dekat menara.
  • Beku — memperlambat, jarang membunuh.
  • Tesla — rantai lightning ke beberapa target.
  • Penembak — jarak jauh, menembus garis.

Meningkatkan

Klik menara yang sudah ada untuk membuka panel peningkatan. Setiap menara punya jalur peningkatan sendiri, dan menjual menara mengembalikan 70% total biaya.

Model AI

Kalau model aktif, dia menyusun gelombang berikutnya: seberapa sulit dan tipe musuh apa yang domina. Kalau model gagal, mati, atau tidak dikonfigurasi, permainan memakai rencana lokal dan tetap berjalan.

Keyboard

  • Spasi — jeda / lanjut
  • 1–5 — pilih menara
  • Esc — batal / tutup
  • N — gelombang berikutnya
